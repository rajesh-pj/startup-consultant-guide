# Hiring a Startup Consultant: Quick Notes

A few practical notes for founders thinking about outside help.

## When it makes sense

- Sales have flattened and the cause isn't clear
- You are preparing to raise money or enter a new market
- The team has never solved the problem you are facing

## How to choose

Start with one clearly written problem and a result you can measure. Ask each candidate how they would approach it, what you will receive and how progress is reported. Be wary of guaranteed outcomes.
